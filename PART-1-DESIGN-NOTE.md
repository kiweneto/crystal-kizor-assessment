# Part 1 — Design thinking and technology note (under 200 words)

I treated the page as a personal-brand ecosystem, not a directory of seven unrelated ventures. The opening statement establishes the shared perspective—designing across spaces, products and systems—before the visitor reaches the initiatives. The initiative cards preserve each brand's distinct purpose, while filters make exploration easier. Three audience pathways translate the broad portfolio into practical next steps for project enquiries, learning and collaboration, and speaking or research.

The visual direction uses editorial typography, warm neutral surfaces, deep green and a restrained lime accent to feel considered and contemporary without overwhelming the content. Responsive layouts, a compact mobile navigation, accessible labels, keyboard focus states, image alt text and reduced-motion support are included. The page uses semantic HTML, custom CSS and vanilla JavaScript. I chose a static implementation because it is fast, easy to understand and deployable from a phone without a build pipeline. The same structure can later be extended with verified project links, real brand assets, analytics events and a secure enquiry form. Temporary imagery and the contact email must be replaced or verified before public submission.
